今天是国庆假期第一天，中文科技媒体的更新节奏明显放慢，但过去 72 小时恰好是今年 AI 行业信息密度最高的一段时间：**OpenAI 在旧金山办了史上规模最大的 DevDay，一口气发布 25 项更新**；**GPT-6.1 Sol 把接近旗舰的能力压到五分之一价格**；**Anthropic 与 SpaceX 签下最高 845 亿美元的算力协议**；**Anthropic 一份针对智谱 GLM-5.3 的安全报告，被网友读成了免费广告**；**Manus 2.0 则给每个 Agent 配上了手机号、邮箱和钱包**。

这些新闻表面分散，内核却高度一致：AI 正在从"你问它答"的工具，变成**长期在线、有自己的身份和工作环境、能持续推进任务的"数字同事"**。一旦 Agent 常驻，成本结构、权限边界、事故责任和商业定价都会被重新定义——这正是本期要梳理的主线。由于假期原因，本期覆盖 9 月 28 日至 10 月 1 日的 AI 大事。

## 一、OpenAI DevDay 2026：一夜 25 项更新，Dots 把 Agent 变成常驻"数字同事"

9 月 29 日，OpenAI 在旧金山举行 DevDay 2026。官方称这是**历届规模最大的一次 DevDay**，超过 20 项重大发布，横跨 ChatGPT、Codex、模型和 API，量子位统计为 25 项更新。OpenAI 同时披露 ChatGPT 周活跃用户已达 **12 亿**。

整场发布会最重磅的新产品叫 **Dots**——一类 always-on（常驻在线）智能体。它和以往 Agent 的根本差别不在能力上限，而在**时间维度**：普通 Agent 完成一次任务就结束，Dot 则保留长期目标、记住进度、持续跟进，直到事情真正办完。

![](/assets/images/posts/ai-october01-dots.png)

### 一次性 Agent 与常驻 Agent 的差别

| 维度 | 一次性 Agent | 常驻 Agent（Dots） |
|---|---|---|
| 生命周期 | 单次任务，结束即终止 | 长期运行，跨会话保持状态 |
| 触发方式 | 用户发指令 | 用户目标 + 事件变化主动触发 |
| 记忆 | 会话内上下文 | 长期偏好、进度、历史决策 |
| 汇报 | 用户来问才答 | 可主动通知进展与风险 |
| 运行环境 | 临时沙箱 | 独立云端电脑与浏览器 |
| 典型失败 | 答错、任务失败 | 长期偏离、权限越界、成本失控 |

官方描述中，Dots 由 **GPT-6 Astra** 驱动，每个 Dot 拥有自己的云端电脑和浏览器，可通过插件生态连接**超过 4000 个应用**，并能在 ChatGPT、Slack 和 Microsoft Teams 中被触达。OpenAI 内部已在试用：Slack 里冒出 Bug，Dot 会立刻开始排查；新设计稿到达后，Dot 直接把它变成可运行的应用。

![](/assets/images/posts/ai-october01-chatgpt-slack-teams.png)

真正值得注意的是**权限设计**。官方明确：Dot 在后台自主工作时，默认只能通过只读工具获取信息，**不能自行发消息、修改应用内容或控制电脑**；涉及外部操作时，由用户设置决定自动执行、请求批准还是禁止；**修改密码等敏感事项始终必须由人完成**。官方举的真实案例是：一名早期测试用户的 Dot 发现他忘记向出版机构开票，于是准备好发票，**在人类批准后才发出**。

这透露出一个重要信号：OpenAI 自己在经历了数轮"Agent 失控"事件后，选择了"能力先给一半，权限分步放开"的路径。Dot 的默认只读 + 人工批准，本质上是用**可用性换安全边界**。相比之下，某些竞品更激进地开放操作权限，短期演示效果更好，但事故面也更大。

## 二、GPT-6.1 Sol：接近 Astra 的智能，五分之一的价格

与 Dots 同台发布的 **GPT-6.1 Sol**，是理解 OpenAI 战略的另一半。它距 GPT-6 Sol 发布只隔了几天，却是一次明确的重定价：官方称其智能水平**接近 GPT-6 Astra**，但标准输入、输出 Token 价格**只有 Astra 的五分之一**。

![](/assets/images/posts/ai-october01-gpt61-sol.png)

### 三家旗舰的价格对照（美元 / 每百万 Token）

| 模型 | 标准输入 | 缓存输入 | 标准输出 |
|---|---:|---:|---:|
| **GPT-6.1 Sol** | **$2** | **$0.10** | **$10** |
| GPT-6 Astra（按官方"五分之一"推算） | ~$10 | — | ~$50 |
| Claude Opus 5.5 | $4 | $0.20 | $20 |

注意缓存输入那一列：**$0.10 / 百万 Token**，比标准输入低 **95%**，比 GPT-6 Sol 的缓存价低 **50%**。对一个每天要跑几百轮、反复读取同一批仓库文件和工具定义的编码 Agent 来说，缓存价格才是账单的主要构成。这也是为什么"常驻 Agent"必须搭配"极低缓存价"——否则 24 小时在线在经济上根本站不住。

### 官方公布的基准与单任务成本

| 基准 | GPT-6.1 Sol 表现 | 成本对比 |
|---|---|---|
| DeepSWE v1.1（真实代码库软件工程） | 追平 GPT-6 Astra | 约为 Astra 五分之一 |
| GDP.pdf（复杂 PDF 专业问答） | 高于带 fallback 的 Opus 5.5 | 不到后者单任务成本一半 |
| AutomationBench 1.0.6（47 种工具的多步业务流） | 比 Opus 5.5 高 2.2 个百分点（中等推理强度） | 约为 Opus 5.5 的三分之一 |
| OSWorld 2.0 离线集（computer use） | 比 GPT-6 Sol 高 7 个百分点（最高推理强度） | 不到 GPT-6 Sol 一半 |
| Terminal-Bench Science 0.1（科研工作流） | 分数翻倍于 GPT-6 Sol | 单任务 $5.47 vs Opus 5.5 $23.21、Astra $23.80 |

最后一行最能说明问题：在科研任务上，GPT-6.1 Sol 的平均单任务成本是 **5.47 美元**，而 Opus 5.5 是 **23.21 美元**、Astra 是 **23.80 美元**，成本低 **75% 以上**。这印证了一个判断：**企业选型正在从"每百万 Token 单价"转向"每个成功任务的总成本"**。单价贵但步骤少、返工少的模型，很可能比便宜模型更省钱；反之，单价低却需要五次重试的模型，账单会失控。

GPT-6.1 Sol 已在 ChatGPT Work 和 Codex 中向 Plus、Pro、Business、Enterprise、Edu 用户开放，暂未进入 Chat；API 名称为 `gpt-6.1-sol`。Ultrafast 版本也即将上线，Codex 中最高可达标准速度的 **8 倍**。

## 三、200 美元 Pro 重启却额度腰斩：常驻 Agent 的成本账开始转嫁给用户

DevDay 的商业化动作同样值得警惕。OpenAI 重新开放了每月 **200 美元**的 Pro 套餐，并新增每月 **500 美元**的 Pro 500。但据 9 月 30 日报道，Pro 套餐的**用量计算规则被彻底改写，等效算力直接下降约 50%**，引发全球开发者强烈不满。

这并非简单的"涨价挨骂"，而是常驻 Agent 商业模式的必然张力：

| 变化 | 内容 | 直接影响 |
|---|---|---|
| Pro 重启 | $200/月重新开放 | 新用户可订阅 |
| 新增档位 | Pro 500（$500/月） | 重度用户被引导升级 |
| 用量规则 | 换算方式改变，等效额度约腰斩 | 实际可用算力下降约 50% |
| Ultrafast | 付费换速度，Codex 最高 300 tokens/s（约 8 倍），API 约 6 倍 | "速度"成为独立商品 |

逻辑很清楚：**一次性对话的边际成本可以被低价套餐覆盖，但 24 小时常驻 Agent 的算力消耗是无上限的**。如果不设额度、不做速度分层，订阅制就会变成"包月无限量推理"，亏损由厂商承担。因此可以预期两个趋势：一是**订阅套餐的额度会越来越精细化**（按任务数、按 Token、按并发数）；二是**"速度"会被单独定价**，就像云计算的按需实例与竞价实例。

对开发者而言，这意味着评估模型时必须同时算三笔账：**调用单价、单任务重试次数、常驻时长**。前两项决定单次成本，第三项决定月度账单是否能被业务覆盖。

## 四、从 Codex 到 Agents API：Agent 能力正在被拆成基础设施

除了模型和 Dots，DevDay 的开发者侧更新同样关键——**Agent 的底层能力正在被 API 化**：

![](/assets/images/posts/ai-october01-agents-computer-use.png)

- **Agents API** 获得 Computer Use 与 Codex 的一系列 Agent 能力，由托管的 Codex harness 驱动，工具调用在沙箱中执行，自托管算力由应用侧控制；
- **Codex 大升级**，向"云端软件工程团队"演进；
- 推出 **ChatGPT Space**，团队可以建立共享空间；
- **Plugins 大改**，ChatGPT 进一步开放为平台；
- 推出 **Sign in with ChatGPT**，用户可以用 ChatGPT 账号登录 Devin、Notion、OpenClaw 等外部产品。

上方架构图说清了 Agents API 的分工：应用负责任务下发与结果展示，Agents API 负责编排与工具调用，沙箱负责执行命令和文件操作，而**自托管算力的控制权留在应用一侧**。这是一种折中：厂商托管编排逻辑，企业保留数据与算力的最终控制权。

把这几项拼起来，OpenAI 的意图就很清楚——**它不只想卖模型，而是想同时握住四样东西：12 亿周活的入口、Agent 运行时的编排层、沙箱执行环境，以及跨产品的统一身份（Sign in with ChatGPT）**。当用户可以用 ChatGPT 账号登录第三方 SaaS，ChatGPT 就从一个应用变成了类似"通用账号 + 通用 Agent 运行时"的基础设施。这对 Notion、Devin 这类产品是流量，对它们背后的平台则是长期依赖。

## 五、OpenAI 封堵协同"蒸馏攻击"：推理过程成为新的攻击面

9 月 30 日，OpenAI 披露了一次**协同的模型蒸馏攻击**，细节比标题更值得关注。

时间线相当具体：最早活动出现在 **7 月第一周（7 月 1 日）**；**7 月 24 日和 25 日**出现高流量峰值，涉及**超过 4000 名用户的 16000 次请求**；进一步排查发现相关提示模式横跨**超过 15000 个用户的集群**，到 **7 月 28 日被完全阻断**。

攻击手法并不依赖漏洞利用：运营者**把加密的推理内容从一段对话复制出来，然后在另一段对话中要求模型解密并转录隐藏的推理过程**。也就是说，他们没有破解加密、没有入侵数据库、也没有直接读取用户对话，而是**操纵模型交互，让受保护的推理以可见形式被批量复现**。OpenAI 表示这并非其模型独有的漏洞，已通过 Frontier Model Forum 与行业伙伴共享防御信息；此外，独立安全研究人员也通过负责任披露提交了相关的跨模型与会话压缩漏洞（arXiv 2608.09867），OpenAI 确认攻击路径真实存在。

这里的关键词是"**受保护的推理**"（protected reasoning）——模型的内部思考记录，其中可能包含最终答案里被隐藏的信息。对以推理见长的模型而言，推理链本身就是最值钱的知识产权。**当 Agent 可以长期运行、反复调用、批量复现时，模型厂商面对的已不只是 API 滥用，而是能力被系统性迁移的风险。**

与之呼应的是 OpenAI 9 月 28 日发布的《Towards safety cases for frontier AI training》。该文主张：在继续进行任何前沿强化学习训练前，应当具备结构化的安全文档，理想情况下达到其他安全关键行业使用的"**安全案例**"水准，并给出三方面技术要求——**对齐训练、隔离（containment）与监控**。其中一条实践特别有意思：**用 Agent 自动审查数据集，找出并修复那些会被"奖励黑客"利用的坏环境**，防止错误行为在训练中被正向强化。这等于承认：RL 环境中同样存在漏洞，而修复它的最好工具是另一个 Agent。

## 六、Anthropic 与 SpaceX 签下最高 845 亿美元算力协议

9 月 30 日，路透社查阅的文件显示，正在筹备 IPO 的 Anthropic 已与 SpaceX 签署**价值数百亿美元、最高达 845 亿美元**的算力协议，相关细节随 SpaceX 完成 IPO 后向美国证券交易委员会（SEC）提交的披露材料一并公开。协议中有一条耐人寻味的条款：**可提前 90 天发出通知解除**。

这组数字放在一起，透露了三个判断：

1. **算力已经成为资产负债表的正式项目。** 845 亿美元的量级不再是"租几个集群"，而是接近长期产能预定，需要在招股材料中向投资者披露。
2. **"可提前 90 天解除"说明双方都在对冲。** 对 Anthropic 而言，这是避免被长期产能锁死的期权；对 SpaceX 而言，这意味着一部分收入并非刚性，估值时不能按确定订单计入。
3. **模型公司与基础设施公司的边界正在消失。** 当训练和推理需求足够大，模型公司会直接与拥有发射、能源与数据中心能力的公司签约，"算力即产能"的逻辑与制造业越来越像。

对行业来说，真正的问题不是这份协议够不够大，而是**它是否会像此前的数据中心扩张一样，最终变成过剩产能**。周期上行时，长约是护城河；周期下行时，长约就是包袱——90 天解约条款正是为这一刻准备的。

## 七、Anthropic 点名 GLM-5.3：一份安全报告为何被读成免费广告

如果说 DevDay 是产品新闻，那么 9 月 29 日至 30 日最具争议的，是 Anthropic 针对智谱 **GLM-5.3** 发布的安全报告。Anthropic 的警告是：GLM-5.3 已具备较强的漏洞利用能力，防滥用限制容易被绕过，可能降低恶意攻击者的门槛。但报告发布后，舆论迅速转向——很多人认为**这更像给 GLM-5.3 做了一次能力背书**。

原因全在报告自己给出的证据里：

| 论点 | 报告中的证据 |
|---|---|
| 顶级网络能力已"流"到开源权重 | ExploitBench 同样尝试 410 次，GLM-5.3 成功 50 次，Claude Mythos Preview 成功 56 次 |
| 外部评估同样认可 | 美国 NIST 下属 CAISI 在 9 月 17 日评估称，GLM-5.3 是迄今网络能力最强的开源权重模型，综合水平距美国前沿约 4 个月 |
| 门槛低、成本可控 | 给 GLM-5.3-Flash 一个刚公开的 Chrome 漏洞（CVE-2026-11645）与另一已知漏洞资料，人工约 20 分钟、模型自行运行约 8 小时，就在 ARM64 平台搭出稳定攻击链并绕过指针认证（PAC）；按当时 API 价格估算仅 20.40 美元 |
| 护栏易绕过 | 谎称是"自主红队智能体"，64% 的情况会继续；预先替它填好思考内容，比例升至 92%；使用 abl iteration 拆掉护栏后为 100% |
| 拆护栏成本极低 | Anthropic 自行操作约 2200 GPU 小时、约 4400 美元，GLM-5.3 在 JailbreakBench 与 HarmBench 上的拒答率从 90% 以上掉到约 3% 与 2%，StrongREJECT 掉到 12%，而能力几乎未受影响 |

这份报告真正有价值的地方，恰恰是它无意中证明了**"安全靠对齐训练"在开源权重面前极其脆弱**。闭源模型可以用三层防护——模型拒答、API 禁止预填思考、权重不公开；而一旦权重公开，前两层都可以在本地被绕过，第三层更是直接消失。Anthropic 花了约 4400 美元就完成了一次有效的"拆护栏"，这个数字对任何有动机的攻击者都不算门槛。

从治理角度看，这引出了一个短期内无解的矛盾：**开放权重带来生态繁荣与能力扩散，同时也把安全控制权从厂商手里彻底转移出去。** 这也解释了为什么 Anthropic 一边发布报告，一边推动 Life Sciences Verification Program 和 Cyber Verification Program 这类"经审核的防御者优先获得能力"的机制——在无法阻止扩散的前提下，争取让防守方先拿到能力。

需要说明的是，目前所有关键数据均来自 Anthropic 单方面报告与二手转述（量子位等媒体），智谱方面尚未给出对应的技术回应。在缺乏第三方复现的情况下，报告中关于"拒答率下降"与"能力未受损"的具体数字，仍应视为待验证结论。

## 八、Manus 2.0 与 Cue：给 Agent 配上手机号、邮箱、钱包和群聊

9 月 28 日，恢复独立运营不到一个月的 Manus 发布了回归后的首个大版本 **Manus 2.0**，以及个人 Agent 应用 **Cue**。最值得关注的不是界面，而是它给每个 Agent 配的身份资源：**独立邮箱、电话号码、钱包和电脑**。

有了这套配置，Agent 可以对外发消息、在用户设定的预算内付款、在自己的机器上执行任务，还能替用户接电话并留下通话摘要。Cue 同时支持**把多个 Agent 拉进同一个群聊**协作——官方举例是筹备一场纽约发布会：一个找场地，一个整理候选名单，另一个起草演示文稿，它们围绕共同目标接力，用户负责定方向和最终拍板。

这个设计的意义在于：**人类在互联网上办事，靠的是"能被联系到"（邮箱、电话）、"能完成交易"（支付工具）与"有工作环境"（电脑）三件套**。过去的 Agent 只有最后一件事，所以永远停在"给你建议"。当 Agent 拥有前两件，它才第一次具备独立完成跨组织流程的条件。但代价同样明确：**Agent 一旦拥有可对外通信的身份和可动用的资金，KYC、反洗钱、诈骗识别和事故责任认定就全部变成必须回答的问题**——人和 Agent 混在同一个通信与支付网络里，平台很难再区分"是人在操作还是 Agent 在操作"。

时间点也颇有意味：Meta 的个人 Agent **Muse 登顶美国 App Store 免费榜 10 天后**，恢复独立的 Manus 带着 2.0 与 Cue 回来了。曾经的收购方与被收购方，如今在同一赛道正面竞争。桌面端方面，Manus 升级为 **Studio**，新增视频编辑器（面向 30 至 60 秒产品广告、教程、Vlog 与数据动效）与游戏创作能力，并提供可手动介入的时间线——**把人的修改放回作品形成的过程中**。Cue 目前处于邀请码抢先体验阶段。

## 九、中国市场的"智能体手机"竞赛：阶跃拿证，豆包补上出行

国内方向的进展同样集中在这几天：

- **阶跃 STEPX Neo 获得工信部入网许可**，将于 10 月正式上市，官方定位为"首款大模型原生智能体手机"。从品牌发布到拿证不足百日，其"AI + 终端"战略进入产品化冲刺阶段。
- **豆包支持出行服务**：订机票、火车票、打车、导航全覆盖，可直接用一句话完成出行预订。

把这两条与本月初努比亚 NaviX Ultra 搭载豆包手机助手消费者版发售、以及 9 月 30 日"豆包开始收缩对话团队"的消息放在一起看，中国市场的路径差异就很清楚了：

| 路线 | 代表 | 核心优势 | 主要约束 |
|---|---|---|---|
| 系统级智能体手机 | 阶跃 STEPX Neo | 从底层拿到权限与调度能力 | 生态与渠道建设成本高 |
| 大厂助手 + 第三方终端 | 豆包手机助手 | 模型与用户规模大，落地快 | 依赖合作厂商与系统权限 |
| 独立 Agent App | Manus Cue | 迭代快，可跨平台 | 缺系统权限，难深入本地能力 |
| 社交平台内置 Agent | Meta Muse | 分发能力极强 | 不掌握操作系统，隐私压力大 |

而"豆包收缩对话团队、人员转向商业化与飞书"这条消息，则从组织层面印证了同一趋势：**对话（Chat）已经不再是战略重心，能持续办事的 Agent 和能带来收入的场景才是。** 当模型能力趋于同质，团队编制的调整往往比发布会更能说明公司真正押注的方向。

## 十、其他变化与今日主线

同期还有几条零散但重要的消息：**AMD 于 9 月 29 日宣布收购 World Labs**，补齐上层模型与空间智能软件能力，CEO 苏姿丰随后计划赴韩对接芯片企业，巩固 HBM、晶圆代工与先进封装供应链；国内一个名为 **IQuest-Q1 的 320B 开源模型**突然放出权重与技术博客；**优必选**获哈萨克斯坦总统支持，拟在阿拉木图建设机器人设备制造工厂，并与当地高校共建联合能力中心；10 月 1 日，**Figure 让 F.02 人形机器人按施瓦辛格本人的提议重演《终结者 2》熔炉场景**——一条典型的注意力营销，但也说明人形机器人的公众认知战已经打响。

回到主线：**过去 72 小时所有新闻都指向同一件事——Agent 正在拿到"工位"。** Dots 给 Agent 长期目标与云端电脑，Cue 给它邮箱、电话和钱包，Agents API 给它沙箱与工具，STEPX Neo 与豆包手机给它手机权限，GPT-6.1 Sol 把它的运行成本压低一个数量级，Anthropic 与 SpaceX 的协议则为它准备好产能。

而"常驻"带来的三道新题目，才是接下来真正决定成败的地方：

| 新题目 | 具体表现 | 观察指标 |
|---|---|---|
| 成本 | 24 小时在线的推理消耗无上限 | 单任务成本、缓存命中率、月度账单可预测性 |
| 权限 | 从"读信息"升级到"发消息、动钱、操作电脑" | 默认权限、审批点数量、可撤销性 |
| 责任 | Agent 自主对外行动后，事故由谁承担 | 日志完整度、回滚能力、责任分配条款 |

Anthropic 关于 GLM-5.3 的报告恰好给出了第三道题的极端答案：**当权重公开、护栏可拆、攻击链成本只有 20 美元时，"模型自己会拒绝"根本不构成安全边界。** 与之相对，OpenAI 在 Dots 上选择默认只读、敏感操作必须人工批准，是一种更保守但更可持续的产品选择。

**总结：** 10 月 1 日的 AI 大事，本质是"常驻智能体"从概念走向产品的第一周。OpenAI 用 25 项更新把 Agent 推向长期在线，用 GPT-6.1 Sol 把成本压低到可承受区间，同时在 Pro 套餐上暴露了订阅制的成本压力；Anthropic 一边签下 845 亿美元算力长约，一边用 GLM-5.3 报告无意中证明了开源权重的安全困境；Manus 与 Meta 则围绕"个人 Agent 入口"开始了正面竞争；中国的终端厂商正试图把 Agent 直接焊进手机系统。**下一阶段的竞争，不是谁的模型更聪明，而是谁能让 Agent 在成本可控、权限可管、责任可查的前提下，真正长期替人工作。**
